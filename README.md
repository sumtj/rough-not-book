# 草稿本 · DraftPad

> 一个**无限画布式便签本**。双击空白处就能打字，截图直接粘贴上去，随便拖、随便缩放 —— 想到什么先扔在画布上，回头再整理。

Windows 桌面小程序，界面用 HTML/CSS/JS 写，外壳用 .NET WinForms 宿主 WebView2 渲染。

---

## 功能

| 功能 | 操作 |
| --- | --- |
| **新建文字便签** | 双击画布空白处，直接开始打字 |
| **粘贴图片** | 直接 `Ctrl` + `V`，截图会变成可拖拽的图片便签 |
| **移动便签** | 按住便签拖动，可放到任意位置 |
| **缩放画布** | 滚轮 |
| **平移画布** | 按住空格拖动，或按住 `Ctrl` 拖动空白处 |
| **调整尺寸** | 文字便签拖右边缘改宽度；图片便签拖角上的方块等比缩放 |
| **缩放提示** | 鼠标移到可缩放的位置，边框会高亮提示 |
| **多份草稿** | 「保存」/「载入」按钮，按名字管理多份草稿；同名会覆盖已有的那份 |
| **撤销** | `Ctrl` + `Z` |
| **删除便签** | 选中后按 `Delete` 或 `Backspace` |

> 💡 不点「保存」直接退出，改动不会留下 —— 这是有意的设计，避免误存半成品。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl` + `Z` | 撤销 |
| `Ctrl` + `V` | 粘贴图片 / 文字 |
| `Ctrl` + `Enter` | 确认（编辑文字时） |
| `Delete` / `Backspace` | 删除选中的便签 |
| `Esc` | 关闭对话框 / 取消编辑 |
| `F11` | 最大化 / 还原窗口 |
| 空格 + 拖动 | 平移画布 |

## 文件说明

```
DraftPad\
├── DraftPad.exe                          # 主程序（.NET WinForms + WebView2 宿主）
├── 草稿本.html                            # 全部界面与逻辑（HTML/CSS/JS 单文件）
├── 草稿本.ico                             # 程序图标
├── Microsoft.Web.WebView2.Core.dll       # WebView2 托管库
├── Microsoft.Web.WebView2.WinForms.dll   # WebView2 WinForms 控件
├── WebView2Loader.dll                    # WebView2 原生加载器
├── drafts\                               # 【本地数据】草稿文件，不入库
└── data\                                 # 【本地数据】WebView2 用户数据，不入库
```

程序的界面逻辑几乎全部集中在 **`草稿本.html`** 这一个文件里，便于直接改样式和交互，无需重新编译。

## 运行要求

- **Windows 10 1809 及以上**（x64）
- **WebView2 运行时**（Evergreen Runtime）

如果启动后白屏，说明系统缺少 WebView2 运行时。安装方式二选一：

1. 从微软官方下载安装：[WebView2 Runtime 下载页](https://developer.microsoft.com/microsoft-edge/webview2/)
2. 如果你已经装了较新的 Microsoft Edge，系统通常已经带了这个运行时

## 使用

双击 `DraftPad.exe` 启动。

### 数据存放位置

程序目录下的两个文件夹（均由程序自动创建）：

| 目录 | 内容 |
| --- | --- |
| `drafts\` | 你保存的草稿，每份一个 `.json` 文件，文件名即草稿名 |
| `data\` | WebView2 的用户数据目录（缓存、配置等），**不要手动改** |

程序是**绿色便携**的 —— 整个目录复制到别处即可，草稿跟着走，不往系统注册表里写东西。

### 备份与迁移

- **备份草稿**：复制 `drafts\` 目录即可
- **迁移到新机器**：复制整个 `DraftPad\` 目录
- **清空缓存**：删掉 `data\` 目录，程序下次启动会重建（会丢失窗口状态等本地缓存，草稿不受影响）

## 草稿文件格式

每份草稿是一个 JSON，记录画布上的所有便签节点。字段结构大致如下：

```json
{
  "notes": [
    {
      "id": "唯一标识",
      "type": "text",
      "x": 120, "y": 80,
      "w": 240, "h": 60,
      "color": "#2d2d2d",
      "content": "便签文字内容"
    },
    {
      "id": "唯一标识",
      "type": "image",
      "x": 400, "y": 150,
      "w": 320, "h": 200,
      "src": "data:image/png;base64,..."
    }
  ]
}
```

- `x` / `y` 是便签在无限画布上的世界坐标
- 图片以 **base64 Data URL** 内嵌在 JSON 里，所以草稿文件可能比较大
- 草稿文件是纯文本，可以自己改，也可以用脚本批量处理

## 本项目不含的内容

为保护隐私，本仓库**有意排除**以下本地数据（见 `.gitignore`）：

| 排除项 | 原因 |
| --- | --- |
| `drafts\` | 个人草稿内容 |
| `data\` | WebView2 用户数据，含浏览历史、Cookies、保存的登录信息、表单自动填充等 |

本地运行时这些目录照常生成和使用，只是不会进入版本库。
